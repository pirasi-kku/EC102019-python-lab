## วิธีใช้ / How to use
1. เปิดโฟลเดอร์ของสัปดาห์นั้น แล้วกดปุ่ม **Open in Colab** ของกลุ่มตัวเอง (ไม่ต้องติดตั้งโปรแกรมใด ๆ)
   Open this week's folder and click **Open in Colab** for your section (nothing to install).
2. **File → Save a copy in Drive** ก่อนเริ่มทำ ไม่อย่างนั้นงานจะไม่ถูกบันทึก
   **File → Save a copy in Drive** before you start, or your work will not be saved.
3. รันเซลล์ "ตัวช่วยตรวจคำตอบ" ก่อน แล้วใช้ `check(...)` ตรวจแต่ละข้อ
   Run the "Answer checker" cell first, then use `check(...)` after each exercise.
4. ทำและส่งในคาบ / Complete and submit in class.

ใครอยากรันในเครื่องตัวเอง ใช้ **Code → Download ZIP** หรือ `git clone` ได้ (ต้องมี Python และ Jupyter)
To run locally instead, use **Code → Download ZIP** or `git clone` (needs Python and Jupyter).
